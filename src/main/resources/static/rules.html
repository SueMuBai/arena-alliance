盟友判定接口 给你自己的 agent 用：出手前先确认目标不是盟友，避免触发拦截与执法

① 你的接入令牌

agent 调用联盟接口的机读凭证（与游戏 apikey 无关，泄露只会暴露联盟名册，请妥善保管；被踢出后立即失效）：

② 接口说明

GET /api/alliance/roster，认证二选一：请求头 Authorization: Bearer <令牌> 或查询参数 ?token=<令牌>。返回：

{
  "success": true,
  "data": {
    "tick": 10583,                      // 名册对应的世界 Tick
    "gameUsernames": ["suemubai", "alice"],   // 全体盟友游戏用户名（判 Core 归属用）
    "allies": [
      {
        "gameUsername": "suemubai",
        "online": true,                 // 该盟友 key 是否在线（离线时名册可能滞后）
        "tick": 10583,
        "idsOnly": false,               // true 时 core/units 只包含 id，不返回坐标或类型
        "core": {"id": "…", "pos": [12, 8]},
        "objectIds": ["…", "…"],        // 该盟友当前存活的全部对象 ID（含 Core 与单位）
        "units": [{"id": "…", "pos": [11, 8], "type": "WORKER"}]
      }
    ]
  }
}

每个成员可在「我的 Key」中把名册隐私设为“仅返回对象 ID”。开启后仍返回 gameUsername 和 objectIds 供盟友判断，但 core / units 中只保留 id，不发送坐标和单位类型。

③ 判定规则（agent 目标选择时依次检查）

  1. 可见 Core：游戏 state 里敌方 Core 自带 owner_username —— 若在 gameUsernames 中 → 是盟友，禁止攻击；
  2. 可见单位：游戏不暴露单位归属 —— 用单位的 id 对照全部盟友的 objectIds，命中 → 盟友单位；
  3. SWEEP/SHOOT 目标格：出手前把目标格与 allies[].units[].pos / allies[].core.pos 比对，有盟友占格就换目标；
  4. 名册每 Tick 刷新，建议 agent 每 15 秒拉取一次并缓存（一个 Tick 一次足够），请求失败时沿用上次缓存并保守处理（宁可不打）。

④ 示例

curl：

curl -s "https://你的平台地址/api/alliance/roster" \
  -H "Authorization: Bearer 你的接入令牌"

Python（接入 arena-hero-agent 一类的 agent）：

import time, urllib.request, json

ROSTER_URL = "https://你的平台地址/api/alliance/roster"
TOKEN = "你的接入令牌"
_cache = {"at": 0.0, "ids": set(), "names": set()}

def refresh_roster():
    req = urllib.request.Request(ROSTER_URL, headers={"Authorization": "Bearer " + TOKEN})
    data = json.load(urllib.request.urlopen(req, timeout=5))["data"]
    _cache["ids"] = {i for a in data["allies"] for i in a["objectIds"]}
    _cache["names"] = set(data["gameUsernames"])
    _cache["at"] = time.time()

def is_ally(object_id=None, owner_username=None):
    if time.time() - _cache["at"] > 15:
        try:
            refresh_roster()
        except Exception:
            pass  # 拉取失败沿用缓存，宁可保守
    if owner_username and owner_username in _cache["names"]:
        return True
    return object_id is not None and object_id in _cache["ids"]
